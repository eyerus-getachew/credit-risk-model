# Credit Risk Probability Model for Alternative Data

## Project Overview

This project develops an end-to-end credit risk scoring system for Bati Bank using alternative behavioral transaction data from an eCommerce platform. Since no direct loan default labels are available, customer credit risk is approximated through RFM (Recency, Frequency, Monetary) analysis and customer segmentation.

The solution covers:

* Credit risk proxy target creation
* Feature engineering
* Model training and evaluation
* MLflow experiment tracking
* Credit score generation
* REST API deployment with FastAPI
* Containerization with Docker
* CI/CD automation with GitHub Actions
